N-grams is a sequence of n words that appear together in text. by counting how often
n-grams occur in a large amounts of text we can capture patterns of language

'Jade was hungry so'
Unigrams(n=1): Jade, was, hungry, so
bigrams(n=2): Jade was, was hungry, hungry so
Trigrams(n=3): Jade was hungry, was hungry so

for instance 'New York City'
we can predict that 'City' is the word that will follow the bigram New York

P(city|new york) = count(new york city)/count(new york)

The context window is very important part of the n-grams model.
for a bigram model the context window is one
for a trigram model the context window is two.
what this means is that the next word is predicted based on the context window
